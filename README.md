# Halo-nuclei-with-Gaussian-potentials
Empirical relations between parameters of one- and two-neutron halo nuclei with Gaussian potentials, calculated data for training and python files.
data.txt contains  data with  nn and n-core potential radii (rnn=1.65 fm and rnc), nc (B2) and nnc (B3) binding energies, nc  scattering (a) and binding (ab) lengths and effective range (ref).
Results explicitly indicated with nn (or nn-phys) correspond to  a_nn=-18.90 fm, otherwise to a_nn = infinity.
gpr-kplin.py provides approximate (linear) analytic relation between nnc binding momentum and nc binding length, as well as the more accurate (near 3b threshold) GPR results.
